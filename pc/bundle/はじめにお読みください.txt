PhonePad  ― スマホをPCのキーボード・マウス・コントローラーにするアプリ
=====================================================================

■ 配布サイト（最新版・過去のバージョン・変更内容）
  https://charlotte5227.github.io/PhonePad/
■ 使い方（画面ごとの使い方・困ったとき）
  https://charlotte5227.github.io/PhonePad/guide.html

■ フォルダの中身
  PhonePad.exe              … PC側のソフト
  ViGEmClient.dll           … コントローラー機能の部品（消さないでください）
  ViGEmBus_1.22.0_setup.exe … コントローラー用ドライバーのインストーラー
  PhonePad_log.txt          … 動作の記録（起動すると作られます。不具合を調べるときに使います）

  ※動作環境: Windows 10/11（64bit）、Android 11 以降。スマホとPCは同じWi-Fiにつないで使います。


■ 1. PC側の準備（毎回）
  1) ダウンロードしたzipを好きな場所に展開し、PhonePad.exe をダブルクリックします。
     ・「WindowsによってPCが保護されました」と出たら「詳細情報」→「実行」。
     ・「Windows セキュリティの重要な警告」が出たら、
       「プライベート ネットワーク」にチェックを入れて「アクセスを許可する」。
  2) PhonePad の画面が開き、接続用のQRコードが表示されます。
  3) 画面を閉じても、PhonePad はタスクバー右下（通知領域）のアイコンで動き続けます。
     ・画面をまた開く … 通知領域の PhonePad のアイコンをクリック（見えないときは「^」の中）
     ・終了する … アイコンを右クリック →「PhonePad を終了」
     ※v2.0.0 から、黒いウィンドウは出なくなりました。

 【自動起動】
  PhonePad の画面の「設定」→「Windowsの起動時に自動で起動する」にチェックを入れると、
  PCの起動時に PhonePad が画面を開かずに自動で動きます（スマホの設定からも切り替えられます）。
  ・自動起動中に画面を開きたいとき … 通知領域のアイコンをクリック（PhonePad.exe をもう一度開いても同じ）
  ・終わらせたいとき … アイコンを右クリック →「PhonePad を終了」

 【PhonePad の画面（PC）】
  ・つなぐ … 接続用のQRコード、iPhone 用のQRコード、アプリを入れるためのQRコード
  ・接続中・履歴 … いま接続中のスマホ（切断もできます）と、接続・切断・拒否・電源操作の記録
      知らないスマホがあったら、切断して「設定」→「接続コードを変更」を押してください。
  ・スマホの設定 … つないだことのあるスマホの ★ショートカット、キーボード画面・コントローラーの配置をPCで変える
  ・アプリごとの配置 … ゲームなど決まったアプリがPCで前に出ている間だけ、スマホの配置を自動で切り替える
  ・バックアップ … スマホの設定をファイルに保存・戻す、機種変更したときに古いスマホの設定を写す
  ・設定 … 自動起動、接続中の表示、接続コードの変更、更新の確認、終了
 【接続中の表示】
  スマホがつながっている間は、画面の右下に「スマホが接続中」と小さく表示されます。
  「切断」を押すと、すべてのスマホを切断します。文字の部分を押すと PhonePad の画面が開きます。
  （スマホに映すPCの画面には写りません。「設定」やアイコンの右クリックで出さないようにもできます）


■ 2. コントローラー用ドライバー（最初に1回だけ）
  PhonePad の画面の「ドライバーをインストール」を押し、画面の指示に従ってください。
  終わったら「再確認」を押し、「使用できます」になればOKです。
  ※キーボード・マウス・音量・画面表示だけならドライバーは不要です。


■ 3. スマホにアプリを入れる（最初に1回だけ）
  スマホのブラウザで配布サイト（https://charlotte5227.github.io/PhonePad/）を開き、
  「Androidアプリ」を押して PhonePad.apk をダウンロードします。
  ※PhonePad の画面（つなぐ）の下にある「スマホにアプリを入れる」の
    QRコードをスマホのカメラで読み取ると、配布サイトがすぐ開きます。
  ダウンロードしたファイルを開き、「この提供元のアプリを許可」をオンにしてインストールします。
  「Play プロテクト」の警告が出たら「インストールする」を選んでください。


■ 3-2. iPhone で使う（ブラウザ版・アプリなし）
  PhonePad の画面（つなぐ）にある「iPhone・ブラウザで使う」のQRコードを、
  iPhone のカメラで読み取ると、Safari で操作画面が開きます。
  Safari の共有ボタン →「ホーム画面に追加」で、次からはアイコンから開けます。
  ・できないこと: 振動、スマホからPCの電源を入れる、PCの自動探索（IPアドレスが変わったらQRを読み直し）、
    配置のプリセット保存
  ・アプリ版より劣るところ: 反応がわずかに遅れることがある、画面の向きを固定できない、
    画面が自動でロックされる、他のアプリに切り替えると切断される（戻ると自動でつなぎ直し）
  ※QRコードには接続用の鍵が入っています。他の人に見せないでください。
    「接続コードを変更」を押すと、ブラウザ版も読み取り直しが必要になります。


■ 4. 更新
  新しいバージョンが出ると、スマホのアプリとPCの PhonePad の画面に「更新しますか？」と表示されます。
  押すとそのまま更新されます。変更内容は配布サイトでいつでも確認できます。


■ 5. 接続
  スマホのPhonePadを開き、「QRコードで接続」→ PCの画面の大きいQRコードを読み取ります。
  「同じWi-Fiで見つかったPC」の一覧から選んでも接続できます。
  2回目からは、アプリを開くだけで同じWi-Fi内のPCを自動で探してつながります。
  PCがまだ起動していなくても、PhonePad が起動した時点で自動でつながります。
  ※通信は暗号化されています。PCの PhonePad を入れ直して「証明書が以前と違います」と
    出たときは、もう一度QRコードを読み取ってください。


■ 5-2. スマホからPCの電源を入れる（Wake on LAN）
  一度つながると、接続画面に「⏻ ○○ の電源を入れる」ボタンが出ます。
  押すと、シャットダウン・スリープ中のPCに電源を入れる合図を送ります。
  ※使うにはPC側の準備が必要です。
    ・PCが LANケーブル（有線）でルーターにつながっていること（Wi-Fiだけだとほとんど動きません）
    ・BIOS/UEFI の設定で「Wake on LAN」（または Power On By PCI-E など）を有効にする
    ・デバイスマネージャー → ネットワークアダプター → 有線LAN のプロパティ
        「電源の管理」で「このデバイスで、コンピューターのスタンバイ状態を解除できるようにする」と
        「Magic Packet でのみ…」にチェック、「詳細設定」で「Wake on Magic Packet」を有効
    ・シャットダウンからも起動したい場合は、コントロールパネル → 電源オプション →
        「電源ボタンの動作を選択する」で「高速スタートアップを有効にする」をオフ


■ キーボード・マウス画面（縦向き）
 【上のボタン】
  🎮 … コントローラー画面へ
  ★ … ショートカット・アプリ起動・クリップボード・PCの状態・PCの電源
  🔊 … PCの音量・ミュート・出力先（スピーカー/ヘッドホン）・再生操作
  🖥 … PCの画面をスマホに表示
  ⚙ … 設定

 【キーボード】
  ・入力欄に打った文字はすぐPCへ送られます（日本語は変換を確定したときに送られます）。
  ・上の「● PC名」に触れると、PCの状態（CPU・メモリ・ディスク・バッテリー・起動時間）を表示します。
  ・入力欄の上に、PCで入力中の欄の内容がそのまま表示されます（複数行も表示）。
    文字に触れると、PCのカーソルがその位置へ移動するので、途中から書き足せます。
    ※メモ帳・Word・ブラウザの入力欄など多くのアプリで使えます。読み取れないアプリでは
      「PCへ送信した文字」の表示になります。パスワード欄は表示しません。
  ・Enter単体 → Enter ／ Shift をタップしてから Enter → Shift+Enter（改行）
  ・Ctrl / Shift / Alt / Win … タップで1回だけ有効、長押しで固定（もう一度タップで解除）
      例: Ctrl をタップ → c を打つ → Ctrl+C
      ※ショートカットはスマホのキーボードを英字モードにして打ってください。
  ・Fn … F1〜F12、Home/End、PgUp/PgDn、半角/全角 などの一覧が出ます。
  ・文字入力中はマウス部分が隠れます。キーボードを閉じると戻ります。

 【マウス（トラックパッド）】
  ・1本指でなぞる … カーソル移動
  ・左側をタップ … 左クリック ／ 右側をタップ … 右クリック（2回タップでダブルクリック）
  ・押したまま少し待つ … そのまま動かすとドラッグ（左側=左ボタン、右側=右ボタン）
  ・2本指でなぞる … スクロール ／ 2本指でタップ … 右クリック
  ・下の「長押し」を押しながらなぞる … スクロール（ThinkPadの中ボタンと同じ）
    「長押し」を押してそのまま離す … 中クリック

 【マウス（スティック）】 左上の「スティック操作」で切り替え
  ・好きな場所に触れると、そこにスティックが出ます（設定で「真ん中に固定」にもできます）。
  ・倒した量に応じてカーソルが動き続けます。
  ・下の「左」「右」 … 押している間マウスボタンを押しっぱなし → 押しながらスティックでドラッグ
  ・「長押し」を押しながらスティック … スクロール


■ ★ パネル
 【ショートカット】
  コピー・貼り付け・元に戻す・Alt+Tab・Win+E（エクスプローラー）などを1タップで送れます。
  「編集」を押すと、ボタンの追加・変更・削除ができます。
    名前、一緒に押すキー（Ctrl/Shift/Alt/Win）、キー（文字や Enter・F1 など）を選んで保存します。
    例: 名前「エクスプローラー」、Win、文字キー「E」→ Win+E
  「アプリ・サイトを開く」を選ぶと、PCでアプリやWebサイトを開くボタンを作れます。
    「PCのアプリ一覧から選ぶ」で、スタートメニューのアプリ（Steamのゲームも含む）から選べます。
    URL（https://…）を入れると、そのサイトをPCのブラウザで開きます。
 【クリップボード】
  スマホ → PC … スマホでコピーした文字をPCのクリップボードへ
  PC → スマホ … PCでコピーした文字をスマホのクリップボードへ
  スマホでコピーした内容をPCに貼り付け … 送ってそのまま Ctrl+V
 【PCの電源】
  ロック／画面オフ／スリープ／再起動／シャットダウン（スリープ以降は確認が出ます）


■ PC画面の表示（🖥）
  ・タップ … その場所を左クリック
  ・長押し … 右クリック ／ 長押ししてから動かす … ドラッグ
  ・2本指 … 拡大・縮小・移動（拡大中は1本指でも移動できます）
  ・上のボタンで「操作 ON/OFF」と「画質（低/標準/高）」を切り替えられます。
    操作OFFのときは見るだけになり、ダブルタップで拡大/元に戻せます。
  ※全画面のゲーム、ロック画面、管理者確認の画面は黒く映ることがあります。
  ※表示されるのはメインのモニターだけです。


■ コントローラー画面（横向き）
  ・PCには「Xbox 360 コントローラー」として認識されます。
  ・ゲームの振動はスマホのバイブで再現されます（設定でオフにできます）。
  ・スティックは、元の位置の周りに触れるとそこに出ます（設定で固定にもできます）。
  ・スティックの遊び・感度・反応カーブは設定（⚙）で調整できます。
  ・⌨ … キーボード・マウス画面に戻る
  ・H … ホームボタン（Xboxボタン）／ L3・R3 … スティック押し込み
  ・T を単体で押す … 全体ターボのON/OFF（ONの間は、押しているボタンが連打になります）
  ・ボタンを押しながら T … そのボタンだけ自動連打のON/OFF（押さなくても連打し続けます）
  ・⚙ … 設定（連打の速さ、ABXYの割り当てなど）
  ・✎ … 配置の編集
      部品をドラッグで移動、2本指で大きさを変更（上の「－/＋」でも調整できます）。
      「初期配置」で元に戻し、「完了」または戻る操作で編集を終わります。


■ 設定（⚙）でできること
  マウスの速さ・加速・スクロールの速さと向き／スティックの出方（触れた位置・固定）
  英数字専用キーボード／連打の速さ／ABXYの割り当て／ゲームの振動／
  スティックの遊び・感度・反応カーブ／コントローラーの配置を初期化
  PC画面の画質／PCの自動起動／ボタンを押したときの振動／接続先のPCの変更


■ うまくいかないとき
  ・つながらない … スマホとPCが同じWi-Fiか、Windowsのネットワークが「プライベート」か確認。
  ・スリープは、PCの種類によっては休止状態になったり、動かなかったりすることがあります。
  ・管理者として実行中のアプリ（タスクマネージャー等）は操作できません。
    操作したい場合は PhonePad.exe を右クリック →「管理者として実行」。
  ・H（ホーム）を押すと Steam や Windows の Game Bar が開くことがあります。
  ・一部のオンラインゲーム（不正対策ソフト付き）は仮想コントローラーやソフトからの入力を受け付けません。
  ・PC側が落ちたり動かなかったりしたら、PhonePad_log.txt に原因が記録されます。
  ・スマホアプリが強制終了したら、次に開いたときに原因が表示されます（「コピー」して伝えてください）。
