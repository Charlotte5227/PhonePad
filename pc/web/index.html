つながらないときは

        
    
          
  1. スマホとPCが同じWi-Fi（同じルーター）につながっているか確認してください。
    2. 
          
  2. 初回起動時の「Windows セキュリティの重要な警告」でプライベート ネットワークへのアクセスを許可してください。
    3. 
          
  3. Windowsの設定で、使っているWi-Fiのネットワーク プロファイルを「プライベート」にしてください。
    4. 
          
  4. コントローラー機能を使うには、上のボタンからドライバー（ViGEmBus）を一度だけインストールしてください。
    5. 
        

      

    


    

      

      

        
iPhone・ブラウザで使う（アプリなし）

        
    
          
  1. iPhone の「カメラ」をこのQRコードに向け、画面に出る黄色い「Safari で開く」（アドレスの表示）を押すと、操作画面が開きます。アプリを入れる必要はありません。
    QRコードだけが大きく写るように近づけてください。周りの文字が写ると、文字の読み取り（翻訳・検索など）が反応することがあります。
    2. 
          
  2. Safari の共有ボタン →「ホーム画面に追加」で、次からはアイコンから開けます。
    3. 
          
  3. 振動・スマホからPCの電源を入れる機能などは使えません。くわしくは操作画面の「ブラウザ版について」を見てください。Android ではアプリ版がおすすめです。
    4. 
        

        
このQRコードには接続用の鍵が入っています。他の人には見せないでください。

      

    


    

      

      

        
スマホにアプリを入れる（Android）

        
    
          
  1. スマホのカメラでこのQRコードを読み取ると、配布サイトが開きます。
    2. 
          
  2. 「Androidアプリ」を押して PhonePad.apk をダウンロードし、開いてインストールします。「この提供元のアプリを許可」をオンにしてください。
    3. 
          
  3. アプリを開いて「QRコードで接続」を押し、上の大きいQRコードを読み取ります。
    4.

    スマホに送る
    
    
    つながっているスマホに、ファイル・ページ・お知らせを送ったり、スマホを鳴らして探したりできます。
    
    
    
      
    送り先
    
      
    
      
    いまつながっているスマホはありません。Android アプリの設定で「アプリを閉じてもPCとつないでおく」をオンにすると、アプリを閉じている間も受け取れます（ブラウザ版はページを開いている間だけ）。
    
    
    
    
    
      
    ファイル
    
      
    ここにファイルをドラッグ＆ドロップ　または　
    
      
    
      
    Android アプリは、スマホの「ダウンロード」の中の「PhonePad」フォルダに保存します。ブラウザ版は、受け取ると画面に「保存」が出ます。
    
    
    
    
    
      
    スマホで開く
    
      
    
      
    　アプリを開いていないときは、スマホに出るお知らせを押すと開きます。
    
    
    
    
    
      
    お知らせ
    
      
      
      
    
        
        
      
    
      
    
      
      
    時間をおいたお知らせは、PhonePad を終了すると消えます。バッチファイルなどから PhonePad.exe --notify "終わりました" と実行しても送れます（--open-on-phone URL、--send-to-phone ファイル、--ring-phone も使えます）。
    
    
    
    
    
      
    スマホを探す
    
      
    
      
    Android アプリは、マナーモードでもアラームの音量で1分間鳴ります。スマホの画面に出る「止める」でも止まります。タスクバー右下のアイコンを右クリック →「スマホを鳴らす」でも鳴らせます。
    
    
    
    
    
      
    スマホから受け取ったファイル
    
      
    保存先: -
    
      
    
      
    スマホでは、Android アプリの ★ →「ファイルをPCへ送る」か、写真などの「共有」→「PhonePad」で送れます（ブラウザ版は その他 →「ファイルをPCへ送る」）。
    
    
    
  
    

  
  
    
    
    スマホの設定
    
    
    つないだことのあるスマホの ★ショートカット、キーボード画面とコントローラーの配置を、PCの大きな画面で変えられます。
    
    
    まだありません。スマホの PhonePad でこのPCにつなぐと、ここに出ます（アプリ・ブラウザ版とも v2.1.0 以降）。
    
    
    
    
    
  
    

  
  
    
    
    アプリごとの配置
    
    
    PCで決まったアプリ（ゲームなど）が前に出ている間だけ、スマホの配置を自動で切り替えます。そのアプリから離れると、いつもの配置に戻ります。
    
    
    
    
    
    
  
    

  
  
    
    
    バックアップ
    
    
    スマホの配置・★ショートカットと、アプリごとの配置をファイルに保存しておけます。スマホを替えたときや、PCを入れ替えたときに戻せます。
    
    
    
      
    ファイルに保存する
    
      
    つないだことのあるすべてのスマホの設定と、アプリごとの配置を1つのファイルに保存します。
    
      
    バックアップを保存
    
    
    
    
    
      
    ファイルから戻す
    
      
    保存したファイルを選ぶと、その内容に戻します。つながっているスマホにはすぐ、ほかのスマホには次につないだときに届きます。
    
      
    
      
    
    
    
    
    
      
    スマホを替えたとき（設定を写す）
    
      
    新しいスマホを一度このPCにつないでから、古いスマホの設定を写してください。
    
      
    写すには、2台以上のスマホをつないだことが必要です。
