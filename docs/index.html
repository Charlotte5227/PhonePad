PhonePad

スマホを、WindowsパソコンのキーボードとマウスとXboxコントローラーにするアプリです。同じWi-Fiにつなぐだけで使えます。

Androidアプリスマホに入れる PhonePad.apk Windows用ソフトPCに入れる PhonePad の zip
最新版を確認しています…

ダウンロードが始まらないときは、このページを Chrome などのブラウザで開いてください。

iPhone の方は、アプリを入れずに使えるブラウザ版をどうぞ（PCのソフトは必要です）。

はじめての方へ

  1. PCにソフトを入れる「Windows用ソフト」のzipをダウンロードして展開し、PhonePad.exe を起動します。「WindowsによってPCが保護されました」と出たら「詳細情報」→「実行」を押してください。
  2. 通信を許可する初回だけWindowsの確認が出ます。「プライベート ネットワーク」にチェックを入れて許可してください。
  3. スマホにアプリを入れるこのページをスマホで開いて「Androidアプリ」をダウンロードし、ファイルを開いてインストールします。「この提供元のアプリを許可」をオンにしてください。PCのブラウザ画面の下にある「スマホにアプリを入れる」のQRコードを読み取ると、このページがスマホで開きます。
  4. つなぐアプリの「QRコードで接続」で、PCのブラウザに表示されたQRコードを読み取ります。2回目からは自動でつながります。
  5. コントローラーを使う場合PCの画面の「ドライバーをインストール」を一度だけ実行してください。キーボードとマウスだけなら不要です。

画面ごとの使い方と、困ったときの対処はこちら（使い方のページ）

動作環境: Windows 10 / 11（64bit）、Android 11 以降（iPhone はブラウザ版）。スマホとPCは同じWi-Fiにつないで使います（ダウンロードはどこからでもできます）。新しいバージョンが出ると、アプリとPCのソフトが「更新しますか？」と知らせてくれます。

できること

  • ⌨
    キーボード日本語もそのまま入力。PCで入力中の欄を表示して、触れた位置から書き足せます
  • 🖱
    マウスノートPCのようなトラックパッドと、触れた所に出るスティック
  • 🎮
    コントローラーXbox 360 コントローラーとして認識。連打、振動、配置・形の変更とプリセット
  • ★
    ショートカットWin+E などのキー操作や、アプリ・サイトの起動を1タップで
  • 🔊
    音PCの音量・出力先の切り替え。PCの音をスマホで聞くこともできます
  • 🖥
    PCの画面スマホにPCの画面を映して、そのまま操作。クリック、スクロール、ドラッグ、文字入力も
  • ⏻
    電源ロック・スリープ・シャットダウン。設定すればスマホからPCの電源も入れられます
  • 📋
    クリップボードスマホとPCで、コピーした文字をやり取り

iPhone で使う（ブラウザ版）

iPhone にはアプリを入れられないため、Safari で使える「ブラウザ版」を用意しています。PCの PhonePad の画面にある「iPhone・ブラウザで使う」のQRコードを iPhone のカメラで読み取るだけで使えます。Safari の共有ボタン →「ホーム画面に追加」で、アプリのようにアイコンから開けます。Android では、アプリ版のほうが快適です。

できること

  • キーボード日本語入力、Ctrl・Alt・Win・ファンクションキー、PCで入力中の欄の表示
  • マウストラックパッド、2本指スクロール、ドラッグ
  • コントローラーXbox 360 コントローラーとして認識。連打、配置・大きさ・形の変更
  • PCの画面の表示と操作
  • ★ショートカット、音量、PCの音を聞く、クリップボード、電源操作
  • 通信の暗号化

できないこと

  • 振動iPhone の Safari には、Webページから振動させる機能がありません
  • スマホからPCの電源を入れるブラウザからは、そのための通信を送れません
  • PCを自動で探すPCのIPアドレスが変わったら、QRコードを読み直してください
  • 配置のプリセット保存、PCのアプリ一覧からの登録
  • 受け取った文字の自動コピー欄を長押ししてコピーしてください

アプリ版より劣るところ

  • 反応がわずかに遅れることがある速さが大事なゲームにはアプリ版が向いています
  • 画面の向きを固定できないコントローラーは横向きで。向きのロックを外してください
  • 画面が自動で暗くなる・ロックされる長く使うときは iPhone の「自動ロック」を長めに
  • 他のアプリに切り替えると切断される戻ると自動でつなぎ直します。PCの音もページを開いている間だけ
  • 上の端からなぞると通知センターなどが出るiPhone の仕組みで止められないため、ボタンは端から離して置いています
  • 画面の端の操作がブラウザに取られることがある「ホーム画面に追加」で開くと減ります
